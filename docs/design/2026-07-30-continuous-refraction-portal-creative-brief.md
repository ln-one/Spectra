# Spectra 连续折射门户创意参考稿

> 本稿仅用于传达产品叙事、关键元素及大致节奏，不是逐帧执行方案，也不是视觉规范。  
> 设计师可以自由调整构图、文案、镜头、节奏、材质和转场，只要最终故事清晰、连续，并自然落到真实 Workbench。

## 想表达的核心

Spectra 接收来自不同形式的资料，先理解并建立一个统一的知识上下文，再把同一份知识转换为六种不同的创作成果。

整个门户不是多个互不相关的功能区，也不是在一个固定舞台里机械切换状态。它更像一段随着页面向下推进的连续镜头：首页中的资料会一路跟随用户，经过理解、汇聚、折射和重新组织，最后进入完整的 Spectra Workbench。

一句话故事：

**多种资料同行而来，汇聚为同一个知识上下文，再折射为多种作品，最终回到一个真实的工作台。**

## 建议的连续故事

### 第一幕：资料已经在这里

首页首先负责建立品牌感和产品方向。

- 左侧可以是标题、介绍语和主要操作按钮。
- 右侧散落着不同类型的真实资料卡，例如 PDF、PPTX、DOCX、图片、表格、音频、视频、Markdown 和 Notebook。
- 卡片沿用 Workbench 中已有的文件图标和类型色彩。
- 卡片可以有轻微空间感或呼吸感，但不需要粒子、霓虹和无意义的持续旋转。

这一幕要让人第一眼理解：Spectra 从用户已经拥有的资料开始。

参考文案：

**让资料，变成正在发生的创作。**

资料、想法与问题，在同一个工作台里被理解、组织并继续表达。

### 第二幕：资料开始同行

用户向下滚动，首屏文案逐渐离开，但右侧资料不是消失后重新出现，而是跟随页面一起进入新的场景。

- 资料卡可以重新排列、改变大小和间距。
- 原本自然散落的状态逐渐变得有秩序。
- 新的标题或说明在空出来的位置出现。
- 资料仍然保持各自的类型、图标和颜色。

参考文案：

**不只是上传。先理解它们之间的关系。**

这一幕主要建立连续感：用户正在带着这些资料向下走。

### 第三幕：从资料中提取知识

每份资料开始释放一些克制的小光点或短光迹。

- 光点代表主题、结构、事实、关系和线索。
- 它们来自资料，但资料卡本身仍然存在。
- 不同颜色的光点逐渐向中央汇聚。
- 汇聚过程中，文件类型的颜色慢慢被统一，最终成为一束干净的白光。

这里需要避免一个逻辑误区：**Source 卡片并没有变成光。**  
白光代表从多份资料中建立起来的统一知识上下文，而原始资料仍然保留，之后还要进入 Workbench 的资料来源面板。

参考文案：

**不同形式，汇聚成同一个知识上下文。**

### 第四幕：白光进入棱镜

白光形成后进入透明棱镜。

- 棱镜应当像一个精密、克制的知识转换器，而不是装饰性的三角形。
- 材质可以是透明玻璃、暖白高光和少量银灰反射。
- 背景不必为了“高级”变成全黑，也不需要强烈霓虹。
- 白光进入后，可以短暂停留在棱镜内部，出现细微折射和结构变化。

参考文案：

**理解之后，选择表达。**

这一幕可以适当留白，让用户感受到“输入已经被理解，输出即将发生”。

### 第五幕：折射为六种创作

棱镜释放六条不同颜色的光，每条光对应一种真实的 Studio Artifact：

1. 智能课件
2. 教学文档
3. 思维导图
4. 互动游戏
5. 随堂小测
6. 演示动画

- 彩色光线应当在白光进入棱镜之后才出现。
- 每条光线到达终点时，对应的 Artifact 卡片出现。
- 卡片可以从光线端点展开，也可以由色光凝聚成形。
- 最终形成“右侧 Source、中间棱镜、左侧 Artifact”的清晰关系。
- Artifact 使用 Workbench 的真实图标、名称和品牌色，不创造不存在的产品能力。

参考文案：

**同一份知识，折射成六种作品。**

### 第六幕：真实产品开始出现

继续向下时，抽象的光学叙事开始转入真实产品。

- Workbench 的外框、顶栏和三栏结构从背景中逐渐浮现。
- 棱镜降低透明度，白光和彩色光线逐渐缩短并消失。
- Source 卡片开始移动到右侧“资料来源”面板。
- Artifact 卡片开始移动到左侧“备课工坊”。
- 中间的智能助手和知识上下文同步出现。

这一幕不应通过突然换画面完成。理想效果是用户亲眼看到刚才的输入和输出被组织进 Workbench。

### 第七幕：完整 Workbench

最终画面是一个正常比例、完整且可信的 Spectra Workbench。

- Source 已归位到右侧资料来源。
- 六种 Artifact 已归位到左侧备课工坊。
- 中间是助手、知识上下文与任务输入。
- 棱镜和光线已经完成使命并自然消失。
- Workbench 应尽量复用真实产品组件和布局，而不是另外仿制一个缩小版。

参考收束文案：

**所有资料、理解与创作，都在同一个工作台里继续。**

CTA 可使用：

**带着你的资料，开始创作。**

## 元素的连续关系

建议把以下连续性视为整个方案最重要的部分：

### Source

`首页散落 → 跟随页面移动 → 释放知识光点 → 暂留在输入侧 → 进入 Workbench 右栏`

Source 不应该在中途消失，也不应该真的变成白光后再凭空出现。

### 知识上下文

`资料释放的线索 → 多色光点汇聚 → 白光 → 进入棱镜`

白光是资料共同形成的知识上下文，不是一种文件。

### Artifact

`棱镜释放色光 → 光线到达终点 → 六张成果卡出现 → 进入 Workbench 左栏`

在折射发生之前，不应提前展示完整的六张成果卡。

### Workbench

`不可见或只留下非常弱的空间暗示 → 轮廓浮现 → 三栏形成 → Source 与 Artifact 归位 → 完整产品`

Workbench 是整段故事的结果，不只是最后追加的一张产品截图。

## 视觉方向

- 以暖白、银灰、透明玻璃为基础。
- 品牌色集中用于资料类型、折射光线和六种 Artifact。
- 首屏可以明亮、有空气感，不使用全黑背景强行营造科技感。
- 光效应当服务于“理解与转换”，避免装饰性粒子和大面积彩色渐变。
- 卡片可以有空间层次，但仍应保持产品 UI 的清晰度。
- 棱镜要精致、透明、可信，避免厚重、塑料或简单线框感。
- Workbench 出现后，视觉逐渐从品牌电影感收束到真实、稳定、可使用的产品界面。

## 动态节奏参考

以下仅是节奏建议，设计师可以根据实际效果重新分配：

1. 首屏与散落资料：建立产品和输入
2. 资料跟随移动：建立连续性
3. 光点提取与汇聚：建立“理解”
4. 白光进入棱镜：短暂停顿和期待
5. 六色折射与成果出现：主要视觉高潮
6. Workbench 浮现和元素归位：从概念回到产品
7. 完整 Workbench 与 CTA：稳定收束

不必让每一幕占用相同的滚动距离。棱镜前可以更克制，折射阶段可以稍快，最后的归位应当清楚、从容。

## 可以自由发挥的部分

- 首屏标题、说明文字和具体排版
- Source 卡片的散落方式与数量
- 光点、光迹或知识提取的视觉语言
- 棱镜的具体形状、材质和内部结构
- 六条色光的曲线、角度和出现节奏
- Workbench 的浮现方式
- 场景之间的背景、镜头和空间变化
- 整体滚动长度及每一幕的停留时间

## 希望保留的底线

- 故事必须是连续的，而不是每屏换一套不相关元素。
- Source、Artifact 和最终 Workbench 之间必须看得出真实对应关系。
- Source 产生知识上下文，但不会被销毁。
- 白光先于彩色折射出现。
- 六种输出必须对应 Spectra 当前真实的 Studio Artifact。
- 最终必须自然落到真实、正常比例的 Workbench。
- 不使用虚假用户数据、评价、价格或不存在的产品能力。
- 这是一份创意参考，不要求照稿执行；如果有更好的表达方式，可以大胆改动。
